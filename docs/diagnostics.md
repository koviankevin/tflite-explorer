# 本機診斷報告

在右上角「版本」選「本機診斷報告」。網站先顯示完整 JSON，按「下載預覽 JSON」才下載，下載內容與目前預覽一致。「更新預覽」重新取得目前狀態；「清除本次操作紀錄」只清除記憶體中的診斷事件，不清除模型、圈選、patterns 或本機草稿。Escape 關閉後焦點回到版本按鈕，不結束圖上的選取。

報告使用固定欄位白名單，包含核心版本／build ID、公開或內網發行類型、來源 commit、瀏覽器種類與主版本、作業系統種類、粗略的檔案／OP／scope／選取數量區間、SVG／Canvas 與繪圖模式、目前操作中狀態，以及草稿啟用／等待恢復／衝突／儲存失敗等布林狀態。缺少量測或版本資料時標記 unknown／null，不用 0 冒充已量測。

不收集模型檔名與路徑、OP／SSA／block 名稱、查詢字詞、pattern 定義、dtype／shape／量化資料、權重、屬性、custom options、私有擴充名稱／版本／指紋、草稿身分、完整 User-Agent、網址、原始錯誤訊息或 stack traces。檔案大小與節點數只留下區間；診斷產生過程不走訪 OP 或權重、不要求 Worker 重新讀模，也不計算模型指紋。版本資訊只讀同站的 `release.json`；讀不到時仍可產生報告，沒有將診斷內容上傳的程式路徑。

目前記錄背景開檔、搜尋、pattern、擷取、圖資料準備、前端繪圖、pattern 清單保存／匯入，以及 UI／全域錯誤的固定操作類別。錯誤只記錄標準例外分類，不保留訊息。耗時用 10ms 取整。每個操作的開始／結束各是一筆事件；最多留最近 64 筆，較舊筆數另計，JSON 上限 64 KiB。紀錄只存在目前分頁記憶體，重新整理後不保留；清除紀錄後，先前未完成操作的結束通知不會重新寫回。

開啟預覽不會強制保存草稿或改變選取。背景操作可能繼續完成；需要最新狀態時按「更新預覽」。版本欄位會比較目前載入模組的 build ID 與取得的版本資訊，不一致時標示 mismatch，協助辨識更新期間的版本混用。

這份報告不是完整效能分析：沒有量測整個瀏覽器程序或 Worker 的記憶體，背景圖資料準備與前端繪圖分開記錄；匯出成功只代表產生檔案，不代表瀏覽器完成下載。沒有執行公司 dialect／runtime 語意或推論驗證。需精確錯誤位置時仍以本機介面的訊息及 MLIR 檢查視窗為準。
