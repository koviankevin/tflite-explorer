# v1.0.1 候選驗收與發布

修正探索草稿、編輯草稿及 pattern 清單的資料庫連線失敗重試；同步拋錯後不再重用失敗 Promise，延遲的舊 error／versionchange 也不會清除新連線。資料庫名稱、schema、上限及交易／CAS 邏輯不變，詳見 [修正與界線](database-open-retry.md)。

穩定版驗收不再只辨識 preview 編號。只有明確的舊 preview 保留原 cutoff；v1.0.x 及其他有效版本要求所有現行案例，無效版本直接失敗。driver 原始報告明列四個 releaseFeatures，獨立 reader 要求全為 true；沒有以版本改名略過示範模型、輸入清理或草稿容量驗證。
