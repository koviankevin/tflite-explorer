# 本機草稿、復原與重做

開啟模型並完成索引、模型結構指紋後，預設自動保存操作狀態。狀態列顯示等待、儲存中、成功時間或失敗原因；只有 IndexedDB transaction 完成才回報成功。初次讀取指紋不讀權重，每次重新開模只建立一次，後續操作不重新掃描模型。

草稿包含搜尋、可用的 pattern 與條件、尚未完成的文字／視覺結構編輯、尚未加入的條件欄位、選取 OP、跨 block 選取、圖形收合／路徑分段、字級、方向、搜尋欄寬度與 SVG／Canvas 視角。不保存模型、權重、worker 快取、匯出 Blob 或整個 pattern library；保存的檔名、OP／pattern 名稱、條件和型別仍可能是內部資訊。

## 使用

- 「自動儲存」可暫停本分頁後續寫入，偏好留在此瀏覽器；暫停不刪除舊草稿，Undo／Redo 和手動下載仍可使用。
- 「本機草稿」可選取保存的版本、下載 JSON，或恢復。重開網站後仍需自行重新選取原模型；恢復前核對檔案大小、格式與結構指紋。只改權重、結構及大小相同時可能通過，這不是權重身分驗證。
- 開啟已有草稿的模型時，先提示恢復或另開，尚未決定前不覆蓋原記錄。不同瀏覽器或不同網站來源（含公開站／公司內網）不共用草稿；換環境請使用 JSON 檔案。
- 「另開草稿，保留原版本」建立獨立記錄。同一模型可有多份草稿，清單列出時間與 revision。
- 移除草稿需展開說明、確認已保存所需備份，再按「移除所選草稿」。這會移除該記錄及上次成功版本；移除前若其他分頁已更新，會拒絕舊版的刪除請求。模型、pattern library 和下載檔不受影響。

## Undo／Redo

使用「復原」「重做」或 Ctrl／⌘ Z、Ctrl／⌘ Shift Z（Ctrl Y 亦可）。文字輸入框維持瀏覽器自己的文字復原。操作通常於約 600 ms 閒置後合併成一個快照；連續輸入可能合成一步。最多 50 份快照、總計 8 MiB，較早的操作歷史會從記憶體移除。Undo 後新編輯會捨棄本分頁的 redo 分支。

歷史只屬於目前分頁及目前模型，重新載入或關模後不保留整串歷史；最新操作狀態仍在草稿。Undo／Redo 還原工作區，不刪除已儲存的 pattern library、下載檔，也不改模型。選取／視角的復原沿用已繪製圖，其他變更按需重搜／重畫；沿用大圖限量及虛擬 Canvas 保護。

## 多分頁與失敗保護

IndexedDB 寫入及移除都在單一 readwrite transaction 核對 revision，再原子提交，拒絕舊版本覆蓋。BroadcastChannel 提早通知同來源其他分頁；不支援此通知時，transaction 的 revision 檢查仍有效。發生衝突會暫停該記錄的自動寫入，自己的操作保留在分頁，可恢復另一版或另開草稿，不自動合併兩份選取。

每份記錄另保留上次成功的工作階段；目前 JSON 或已支援格式損壞時可回退讀取這份備份。未知的新格式不當作損壞舊檔覆寫，也不以舊備份蓋掉它。切換模型時，尚在完成的舊寫入仍綁定原本的模型，不會把新模型寫到舊記錄。

每份工作階段最多 2 MiB；最多 20 份草稿，每份最多保留目前與上次成功兩個版本。額度、儲存權限或空間不足時明示失敗，不回報已保存；可下載 JSON 或移除已備份草稿。瀏覽器清除網站資料、私人模式結束或儲存空間回收仍可能移除記錄；重要工作請保留下載備份。關閉／凍結頁面前的最後一個尚未完成 transaction 不保證成功，以畫面上的成功時間為準。

## 格式及部署

工作階段 v2 加入 `state.editor` 草稿；仍可讀 v1。新的手動「上次儲存」使用獨立 localStorage key `model-lens.workspace.v2`，未有 v2 時可讀原本的 v1 key，原 key 不覆寫。自動草稿使用獨立 IndexedDB `model-lens.local-drafts.v1`，不改 pattern v3 library。舊版網站無法讀 v2 JSON；回退前請保留原本相容的檔案及新備份，不假設資料能隨程式自動降版。

需要瀏覽器支援 IndexedDB、Web Workers 及 Web Crypto SHA-256；公司部署請使用 HTTPS（localhost 可用）。不具備安全 context／儲存能力時會明示不可用，不上傳模型來代替驗證。草稿無法寫入時仍保留能運作的本分頁歷史及手動下載；模型結構指紋本身無法建立時，恢復及歷史均不冒用虛構指紋。
