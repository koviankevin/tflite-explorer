# 選取模式內切換連線（2026-10-24）

精簡 MLIR 圖的連線點擊與 Enter／Space 在選取模式中可展開、收起路徑。側欄的逐段與全部收起也可操作；重繪期間暫停操作。保留以原始 block／OP 編號記錄的選取集合、綠色標示、名稱、縮放與路徑定位，完成後可繼續跨 block 框選、存 pattern 或匯出 MLIR。

這裡的「選取途中」指在選取模式中分次框選。按下滑鼠拖出框線仍是框選手勢；放開後才提交新增的 layers。若重繪取消尚未完成的選框，先前已提交的選取仍保留。輔助節點不參與 pattern，收起路徑不移除原始 OP 選取。

## 驗證範圍

- `rectangle-selection`、`pattern-selection`、`mlir-slice-graph`、`svg-viewport`：24 通過。新案例先選兩個 blocks，在匯合／迴圈路徑展開與收起後保留 Set 與原始位置，再增加其餘 OP；capture、搜尋及局部匯出重開仍為六個原始 OP、一次匹配，SSA 檢查通過。
- 本機瀏覽器使用 32px、有分支、匯合、迴圈與 custom op 的模型，先框選三個 blocks 的三個 OP；保持選取模式，滑鼠點連線展開後仍為三個；側欄收起、鍵盤展開迴圈與再次收起仍保留三個。縮放後框選另外兩個 blocks，合計五個 blocks、六個 OP。
- 正式站補驗同一使用者流程、儲存搜尋、實際下載 MLIR 與重新選檔。產物、選取狀態、原生編譯器與 pattern 比對紀錄保存在本任務的 `mid-pick-formal-*` 驗證檔。
