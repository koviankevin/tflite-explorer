# 局部連線快取與分段展開（2026-10-24）

連線拓樸不再經由整個 function 的 display DTO 建立；使用已驗證的 region 索引建立鄰接表。原始 OP、argument、出口與順序控制邊保持獨立身份，只將當前段落的節點轉成顯示資料。拓樸索引依模型及 region 隔離，關閉檔案後隨 worker 模型一起釋放。

路徑計畫使用雙向可達集合保留分支、匯合與迴圈，遇到其餘原始 OP 停止。以 generator 對鄰接遍歷計數，每次預算 50,000；未完成計畫可續算，完成計畫在切段時直接重用。每段預設 96 個輔助節點，總顯示預算 512，包括收合標記；多路徑共享節點去重。未顯示的 connected components 收合成顯示標記，所有邊界 SSA／控制連線保留；極端大量 components 會共享明示的收合標記，該標記不代表可執行的 OP 或精確內部結構。

快取上限為每 region 16 個計畫、每模型 4 個拓樸索引、1,024 個節點模板。閒置計畫以 100,000 條邊、閒置拓樸以 100,000 個節點加邊作為 LRU 回收目標；目前使用中的計畫／單一索引允許超過目標，以免「繼續分析」反覆重頭開始。最多同時開啟 16 條路徑。原始模型記憶體不受此顯示上限限制。
