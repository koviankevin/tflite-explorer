# 筆電可用畫面驗證（2026-10-25）

基準來源 `ab7bfb9`，建置 release `d408969f7e3cd305`。使用 Edge 的 viewport 模擬；未宣稱使用實體 14 吋面板量測。畫面可讀性受解析度、Windows 顯示縮放及瀏覽器工具列影響，因此以 CSS 可用畫面尺寸驗證。

改動：筆電寬度的固定搜尋按鈕、保留字級的間距調整、側欄暫時限寬、右側詳情開啟後定位所點 OP。左右編輯／結果清單保留各自捲動；`overflow:clip` 避免瀏覽器焦點將整個固定左欄捲走。寬度設定不因暫時限制而覆寫；在大視窗測得原偏好 550px 恢復。

上述筆電案例逐一量測：頁面 scrollWidth 等於可用寬度；左欄標題不被捲走、底部授權列留在左欄內；結果區至少 90px；固定搜尋按鈕位於左欄內；模型圖未被圖形工具列重疊。控制文字 14px、圖字 32px。

1280×720 開啟詳情時，左欄 305px、模型圖 600px、右側詳情 375px。所點 Transpose 節點位於模型圖可見範圍。圈選時左欄恢復 448px、模型圖 832px，選取工具列 bottom=293px，模型圖 top=305px，保留 12px 間距。圖形縮放未重設。

實際操作：TFLite 範例的四筆 pattern；N2 dtype `float32` 得 4 筆，再加 `int8` 得 0 筆，移除後恢復 4 筆。條件欄位深處操作後，固定搜尋仍能執行，左欄 scrollTop 維持 0。Layers 分頁不顯示 pattern 快捷按鈕。
