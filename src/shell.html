比對 operator 類型與連線，不比對 layer 名稱。N1 是查詢別名，相同別名代表同一個節點。每行可描述一條分支，也可用 FC = FullyConnected、BMM = BatchMatMul。

選 operator，再選連線的起點和終點。節點編號自動產生；不需輸入模型 layer 名稱。

條件篩選 · 0 個

所有條件都需符合。Shape 的 * 代表任意維度，? 代表動態維度；dtype／attribute 值依詳細資料填寫。只讀 metadata，不讀取權重。

依 tensor 直接連接的順序匹配，允許分支；不限制參數。

新版局部匯出會保留結構對照，既有 pattern 可繼續使用。較早的局部檔案需從原模型重新匯出一次。
